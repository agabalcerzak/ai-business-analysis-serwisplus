# Słownik biznesowy

Status: robocze definicje na podstawie briefu, wypowiedzi interesariuszy i reguł; do potwierdzenia z właścicielką procesu.

## Pojęcia

| Pojęcie | Znaczenie |
| --- | --- |
| **Zgłoszenie** | otrzymana informacja klienta o problemie urządzenia biurowego. |
| **Rejestracja** | zapisanie sprawy, również niekompletnej ([reguły](03-reguly-biznesowe.md), punkt 1). |
| **Pierwsze przekazanie** | skierowanie sprawy do techników po kontroli czterech pól i decyzji konsultanta ([reguły](03-reguly-biznesowe.md), punkty 2, 4 i 7). |
| **Obserwowalny objaw** | opis zachowania urządzenia; nie jest ustaloną diagnozą ([głosy interesariuszy](02-glosy-interesariuszy.md), Piotr; [reguły](03-reguly-biznesowe.md), punkt 8). |
| **Kompletność do przekazania** | cztery wymagane pola bez braków i sprzeczności; numer seryjny jest opcjonalny ([reguły](03-reguly-biznesowe.md), punkty 2–4). |
| **Propozycja gotowości** | roboczy wynik wsparcia AI, który konsultant musi sprawdzić; nie jest wykonanym przekazaniem ([brief](01-brief-projektu.md); [reguły](03-reguly-biznesowe.md), punkt 7). |
| **Zwrot** | odesłanie sprawy po przekazaniu z powodu braków lub niejednoznaczności; dokładna definicja pomiarowa pozostaje do uzgodnienia ([brief](01-brief-projektu.md)). |

Materiał fikcyjny. Stan przed warsztatem; do modułów 2–4.
