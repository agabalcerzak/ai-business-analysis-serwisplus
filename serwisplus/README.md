# SerwisPlus — materiały uczestnika

AI w analizie biznesowej · Agnieszka Balcerzak · InProgress.

**Zacznij od [workbooka: instrukcje i prompty krok po kroku](workbook.md).** Całe studium przypadku jest fikcyjne. Nie zawiera danych prywatnych, rzeczywistej korespondencji ani rzeczywistych klientów.

## Układ materiałów

- Pliki 01–08: kontekst organizacji, projektu, reguł i interesariuszy.

- [Maile](maile/): osobne wiadomości z datą, nadawcą, odbiorcą, tematem, identyfikatorem i treścią.
- [Rezultaty](rezultaty/): przykłady do wykorzystania na wskazanym etapie; miejsce na własne wyniki po pobraniu pakietu.
- [Workbook](workbook.md): jedyny plik z przebiegiem pracy i promptami; podział na osiem modułów.

## Status i pochodzenie informacji

SP-01 wyznacza kierunek, SP-02 zawiera wypowiedzi, SP-03 — zatwierdzone reguły w fikcyjnym scenariuszu. Karty SP-K01–04 i przykłady 09–12 są opracowaniami dydaktycznymi; nie ustanawiają zatwierdzonej architektury, polityk, narzędzi ani mandatów.

Notatki R01–R03 i maile E01–E02 są adaptacjami SP-01–03. Pytania analityczki, nagłówki korespondencji i organizacja spotkań są elementami fikcyjnego scenariusza. Wielokrotne przedstawienie tej samej informacji nie jest niezależnym potwierdzeniem.

Mail 15 jest kanonicznym zapisem SP-04, a mail 18 — SP-07. Nie mają drugiej kopii w rezultatach. SP-04 zawiera późniejsze decyzje z przypisanym zakresem zatwierdzenia; nie jest wynikiem warsztatu przeprowadzonego przez uczestników. SP-06 to celowo wadliwy szkic. SP-07 rozróżnia zatwierdzenie, dzień analizy i wejście zmiany w życie.

Nie uzupełniaj luk dotyczących narzędzi, budżetu, polityk, progów czy uprawnień domysłem. Symulacja AI nie tworzy decyzji interesariusza.

## Jak otworzyć pliki

Czytaj Markdown bezpośrednio na GitHub albo pobierz repozytorium przez **Code → Download ZIP** i otwórz folder `serwisplus`. Oba dni można przejść w bezpłatnym czacie, kopiując potrzebny tekst. Model nie otrzymuje dostępu do prywatnego repozytorium przez samo wklejenie linku.

Własne wyniki zapisuj w lokalnym folderze `rezultaty/`, z oznaczeniem modułu i grupy. Profili osobistych nie musisz udostępniać. Nazwy plików technicznych `AGENTS.md` oraz rozszerzenie `.md` zachowują swoje znaczenie; treść opracowujemy po polsku.
